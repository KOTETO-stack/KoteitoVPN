# Кандидаты в источники — механизм добавления новых источников без правки кода.
#
# Как это работает:
#  1. Ты добавляешь сюда новую ссылку (одна строка = одна ссылка), как обычно
#     редактируя файл на GitHub.
#  2. Раз в сутки workflow "Expand Sources" (scripts/promote_candidates.py)
#     сам проверяет каждую ссылку отсюда: реально ли по ней лежат рабочие
#     vless/trojan/hysteria2 конфиги.
#  3. Если ссылка рабочая (отдала минимум 3 валидных конфига) — она
#     автоматически переносится в sources.txt и удаляется отсюда.
#  4. Если ссылка не сработала — остаётся здесь и будет проверена ещё раз
#     на следующий день (мало ли, источник временно недоступен).
#
# Ничего ломать не может: скрипт только читает публичные URL и парсит текст
# по тому же регэкспу, что и основной сборщик — никакого выполнения кода.
