KoteitoVPN — авто-подписка для Karing / Hiddyfi

Что делает система

Workflow 1 — collect_and_test.yml (каждые 6 часов): сбор конфигов из sources.txt → фильтр (без WARP/Tor/мусора) → TCP-пинг (≤500мс) → DNS-проверка → output/raw_servers.txt.

Workflow 2 — build_subscription.yml (через 20 мин после первого): берёт raw_servers.txt → повторная фильтрация/пинг → гео-определение через ip-api.com (страна/город на русском + флаг) → маскировка Xray (uTLS fingerprint) → лимит 150 серверов, лучшие по пингу → output/subscription.txt — финальная ссылка для Karing/Hiddyfi.

Никаких внешних Python-библиотек не нужно — всё на стандартной библиотеке. Репозиторий публичный → Actions-минуты бесплатны без лимита 2000 мин/мес.

Установка

Залей всю структуру в публичный репозиторий.
Settings → Actions → General → Workflow permissions → Read and write permissions.
Запусти оба workflow вручную первый раз (Actions → Run workflow).
Ссылка подписки: https://raw.githubusercontent.com/<аккаунт>/<репо>/main/output/subscription.txt

Проверка

Если workflow отрабатывает подозрительно быстро и output/subscription.txt пустой:

Permissions на Read/write не включены → git push у бота не проходит молча.
sources.txt не найден по пути — не переноси файл из корня.
Все источники недоступны — смотри лог шага collect_sources.py.
